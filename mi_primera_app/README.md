# sistema de calificaciones

## Descripcion
esta aplicacion permite registrar materias,
asignarles una calificacion y consultar 
el promedio de las notas registradas 

## tecnologias utilizadas 
- python
- streamlit
- pandas 

## instalacion

instalar las dependencias o paquetes necesarios 
pip install streamlit pandas

## ejecucion 

streamlit run "ubicacion o nombre del archivo a ejecutar"
